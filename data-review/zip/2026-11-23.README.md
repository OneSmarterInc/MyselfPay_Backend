# MySelfPay directory ZIP audit | 2026-11-23

Source: repository root `US_Self_Pay_Imaging_Directory.csv` at Git blob `3099c8a1cb164f1f1c1dce820c626895f793d83d`. This audit covers all 5,390 source records from that snapshot. It does not count unique physical businesses, reconcile separate daily batches, or publish to the live database.

- `2026-11-23.center-zips.csv` has exactly one row per `source_record_id`. `zip5` is a five-character string, not a number. Preserve leading zeroes. Join on `source_record_id` to the source column `Stable source record ID`; do not join by center name or city alone.
- All 5,372 single-location records have a ZIP: 4,989 Main, 339 Pending and 44 archived. Pending and archived records did not change category or become eligible to publish.
- The remaining 18 rows are grouped/network entries and deliberately have no single ZIP. `branch_zips_non_importable` is informational where operator sites corroborated candidate branches; those values must not be used as a center ZIP or multiplied into new facility records without reconciling the address and existing branches.
- 122 rows are in `2026-11-23.zip-changes.csv`: 112 Main, eight Pending and two archived. The log identifies supplied, corrected or previously conflicting ZIPs. It does not imply that all 122 pre-existing address strings lacked five digits.
- 149 location records have provider or public-authority evidence consulted for this audit. The other 5,223 ZIPs came from existing site-address fields and were checked for state consistency using [Census ZIP Code Tabulation Area to county relationships](https://www2.census.gov/geo/docs/maps-data/data/rel2020/zcta520/tab20_zcta520_county20_natl.txt). That is not a fresh facility-by-facility address or USPS deliverability check. Institutional postal ZIPs may not appear as ZCTAs; retained exceptions had address-specific support. `source_url` on copied directory addresses is the source already recorded for the row, not a representation that it was re-opened.
- An exact location ZIP does not prove the site is operating, accepts self-pay, or offers a particular scan. Existing location, pricing and publication holds remain in force. Do not convert group, Pending or Archive rows into new published sites from this data.
- Only the ZIP review artifacts are added; the source CSV, application code and live database are unchanged.
